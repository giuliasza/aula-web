Aula 1 – Introdução ao HTML

Construindo a estrutura do site

🎯 Objetivos

  • Entender o que é um algoritmo
  • Conhecer Front-end e Back-end
  • Aprender ferramentas (VS Code)
  • Criar o primeiro arquivo HTML

🧠 Algoritmo

  • Algoritmo = passos em ordem.
  • Exemplo: Receita de bolo.
  • Computadores seguem esses passos.

🖥️ Front vs Back

  • Front-end: O que você vê (Tela).
  • Back-end: O que acontece por trás (Servidor).

🛠️ Ferramentas

  • Usaremos o Visual Studio Code.
  • Editor de código facilita nossa vida (colore o código).

🧩 VS Code

  1. Abra o programa.
  2. Crie uma pasta na área de trabalho.
  3. Arraste a pasta para dentro do VS Code.

📂 Arquivos

  • Todo arquivo tem nome e extensão.
  • Imagens: .jpg, .png
  • Sites: .html

📄 index.html

  • O arquivo principal do site SEMPRE se chama index.html.
  • O navegador procura por esse nome automaticamente.

🌐 O Navegador

  • Nós escrevemos o código.
  • O navegador (Chrome/Edge) lê e desenha na tela.

10. O que é uma tag?

  • É um comando entre < e >.
  • A maioria tem abertura e fechamento.
  • Exemplo: <tag> Conteúdo </tag>

11. O esqueleto obrigatório

  • <html>: A caixa que guarda tudo.
  • <head>: Configurações (o cérebro).
  • <body>: O corpo (o que aparece na tela).

12. Nossas Primeiras Tags

Essas tags ficam DENTRO do body:

  • <h1>: Título Principal.
  • <p>: Parágrafo de texto.

13. Hora de Digitar

Digite isso no seu VS Code:



  
    Minha Página
  
  
    
Meu Primeiro Site

    
Olá, mundo! Estou aprendendo HTML.

14. Ver o Resultado

  • 1. Salve o arquivo (Ctrl + S)
  • 2. Abra a pasta
  • 3. Clique duas vezes no index.html

15. Ciclo de Mudanças

  • Mude o código -> Salve (Ctrl+S)
  • Vá no Chrome -> Atualize (F5)

16. Erros Comuns

  • 🚫 Esquecer de Salvar.
  • 🚫 Salvar como .txt.
  • 🚫 Escrever fora do body.

17. GitHub

Futuramente usaremos o GitHub para colocar o site na internet.

18. Parabéns!

Você criou sua primeira página.

Próximo passo: Deixar ela bonita com CSS.

🎨 AULA 2: CSS

Dando vida e cor ao Portfólio

Cascading Style Sheets

1. O que é CSS?

  • HTML cria o conteúdo (texto, imagens).
  • CSS cuida da beleza (cores, fontes, posições).
  • Analogia: O HTML é o manequim, o CSS é a roupa.

2. HTML vs CSS

Sem CSS

Título

Texto feio.

Com CSS

Título

Texto estiloso.

3. Onde o CSS fica?

  • Pode ficar junto com o HTML (bagunçado).
  • Melhor opção: Em um arquivo separado.
  • Vamos criar o arquivo: style.css

4. Criando o Arquivo

  1. No VS Code, clique em "Novo Arquivo".
  2. Digite o nome: style.css
  3. Agora temos index.html e style.css lado a lado.

5. Ligando os Pontos

O HTML não adivinha que o CSS existe. Precisamos criar um link.

No <head> do HTML, adicione:
Se não fizer isso, nada funciona!

6. A Fórmula do CSS

QUEM { O_QUE: COMO; } 

h1 {
  color: blue;
}
  • Seletor (h1): Quem eu quero mudar.
  • Propriedade (color): O que eu vou mudar.
  • Valor (blue): Como vai ficar.

7. Primeiros Estilos

Vamos testar no arquivo style.css:


body {
  background-color: lightblue; /* Fundo da página */
}

h1 {
  color: white; /* Cor do texto */
}

Salve e atualize o navegador!

8. Tipografia (Fontes)

Vamos tirar a "cara de documento antigo".


body {
  font-family: Arial, sans-serif;
}

Isso deixa o texto mais moderno e legível.

9. Espaçamento (Box Model)

MARGEM (Fora)
PADDING (Dentro)
CONTEÚDO
  • Margin: Empurra os vizinhos.
  • Padding: Engorda a caixa (preenchimento).

10. Cores

  • Nomes: red, blue, gold.
  • Hexadecimal: #ff0000 (mais profissional).
  • Dica: No VS Code, passe o mouse na cor para escolher outra.

11. O poder das Classes

E se eu quiser estilos diferentes para tags iguais?

Usamos Classes (Apelidos).

HTML:

Oi

CSS (Usa ponto):

.destaque { color: red; }

12. Criando Cards

Vamos criar caixas para o portfólio.


.card {
  background-color: white;
  padding: 20px;
  border-radius: 10px; /* Bordas redondas */
  box-shadow: 2px 2px 5px black; /* Sombra */
}

13. Interatividade (Hover)

Mudar quando passa o mouse:


.card:hover {
  background-color: gold;
  cursor: pointer; /* Mãozinha */
}

14. Organização

Use comentários para não se perder:


/* Estilos do Cabeçalho */
header {
  background: black;
}

/* Estilos dos Projetos */
.card {
  margin: 10px;
}

15. Erros Comuns no CSS

  • 🚫 Esquecer o ; no final da linha.
  • 🚫 Esquecer o . antes do nome da classe.
  • 🚫 Escrever font-color (o certo é só color).
  • 🚫 Não linkar o arquivo no HTML.
